# 智能剪贴板（smart-clip）

> 复制的内容经「内置切分器 → 自定义提取规则 → 智能切分」单层管线加工成片段，配合 `Ctrl+B` 环形气泡窗与 AI 分析逐段消费。

由代码审查整理于 2026-10；2026-11 按 `.docs/ctrl-b-refactor-design.md` 收敛为单层模型（方案 / AI 提取器下线）。

## 功能总览

| 功能 | 说明 | 入口 / 快捷键 |
|---|---|---|
| 处理开关 | 关闭直通单段原文；开启进入单层切分管线 | 设置 → 智能剪贴板（—） |
| 自定义提取规则（高级） | 正则 / 分隔符两类规则，按列表顺序执行、首个产出 ≥2 段即生效；默认折叠、零配置也可用，上限 10 条 | 设置 → 智能剪贴板 → 自定义提取规则（—） |
| 内置切分器 | 链接 / 邮箱 / 分词，编译进代码、用户不可见不可编辑 | 管线自动（—） |
| 智能切分 | 本地兜底层：JSON/链接/日志行/多行/分隔符结构识别 + 关键词分词，零配置 | 管线自动（—） |
| AI 分析 | `Ctrl+B` 触发：八级分流后仅散文发起单次调用，产出关键词 + 要点 + 一句话总结 | `Ctrl+B` |
| AI 提供商 | OpenAI 兼容 / Anthropic 原生 / 自定义 JSON（一份 JSON 描述任意 HTTP 接口），支持 SSE 流式 | 设置 → AI 提供商（—） |
| 环形气泡窗 | 片段成环排列（8 槽/环，最多 24 段），环心控制盘展示原文预览与导航 | `Ctrl+B`（局部） |
| 环内导航 | 空间最近邻选中 + 翻页（翻页后选中该页首项） | `↑↓←→` / `PgUp` `PgDn` |
| 环内粘贴 | 粘贴选中片段到目标应用并关环 | `Enter` |
| 关闭环 | 销毁 overlay（失焦自动关环） | `Esc` / 失焦 |
| 钉住片段 | 任意片段创建为独立常驻小气泡窗（点击复制，不模拟粘贴） | 环内钉住按钮（—） |
| 二维码切分 | 剪贴板为图片且 10 秒内入库并识别出二维码时，把二维码文本作为本次内容参与切分，`Enter` 直接粘贴 | `Ctrl+B` |
| 习惯画像 | 粘贴行为/AI 采纳本地采集，仅用于本地统计与缓存分区，**不进入 AI 请求** | 自动（—） |
| 敏感脱敏 | 散文夹密钥：发送前把命中的 token 替换为 `[REDACTED]` | 自动（—） |
| 失败原因可读化 | AI 错误按类别（网络/超时/HTTP/模型）映射为灵动岛可读文案 | 自动（—） |

## 关键行为

### 处理管线（入库即解析）
- 文本入库广播 `smart-clip:copy`（仅文本，图片/文件不进管线）→ `processByMode` 按当前模式解析 → 结果进内存 store（气泡窗口只读，容量 30 条）。
- `off` 直通单段原文；`on` 走单层切分管线（结构层 → 技术保护 → 内置精确切分器 → 自定义规则 → 内置分词 → 关键词/分块 → 原文）。
- 设置页变更推送配置快照（`mode/rules`）并递增版本号，旧解析结果随之失效。
- 实现：`app/src/smart-clip/smartClip.ts`、`app/src/smart-clip/pipeline.ts`、`app/components/setting/SettingMain.vue`。

### 单层切分管线
- 规则引擎纯函数无 IO、永不抛错：非法正则等异常降级为原文单段。
- 正则提取有捕获组时每次匹配的捕获组各成一段（如 URL 提取 host/path），无捕获组按整体成段，零宽匹配 lastIndex 前进防死循环。
- 自定义规则存 KV `clip_extract_rules`（`{v, list, disabledAi}`），最多 10 条；列表顺序即执行顺序，**首个产出 ≥2 段的规则生效**（first-match-wins），禁用/空表达式/非法正则自动跳过。
- 旧 KV `clip_extractors` 首次读取时一次性迁移：内置项丢弃（已编译进代码）、自定义 regex/separator 保留、自定义 AI 提取器只计数（设置页提示已停用）；旧键不删除，便于回滚。
- 内置切分器：URL → 邮箱（精确，排在自定义规则之前）→ 分词（兜底，排在自定义规则之后，保证规则有机会生效）。
- `clip_schemes` 表与 `smart_default_scheme_id` 软弃用：数据保留、不再读写。
- 实现：`app/src/smart-clip/ruleEngine.ts`、`app/src/smart-clip/extractors.ts`、`app/src/smart-clip/pipeline.ts`。

### 方案与 AI 提取器（已下线）
- 原「提取器 + 方案（成员编排 + body 模板）」两级模型与 AI 提取器（`ai_netdisk` / `ai_summarize`）已移除：方案不再执行、body 模板不再渲染、AI 草稿生成入口删除。
- 提炼能力改由 AI 分析承担：一次 `Ctrl+B` 的 AI 调用从 0–3 次收敛为 0–1 次（仅散文分析）。
- 旧 KV `clip_extractors` 与 `clip_schemes` 表数据保留，回滚代码即可恢复旧编辑与执行路径。

### 智能切分（autoSplit）
- 结构化优先：JSON（≥2 元素/键值对）→ 链接/邮箱（≥2 且覆盖率 ≥50%）→ 日志行结构 → 多行 → 分隔符竞标 → 关键词分词 → 原文兜底。
- 切分上限 24 段，超出部分拼接回末段不丢内容；超长单块（>上限字数且无结构可切）按句读/空白边界分块（约 300 字/段，≤24 段）。
- 多行散文误伤修正：平均行长 >60 字视为散文段落不判结构化。
- 切分只拆不改（除空白修剪），清洗 BOM/零宽字符。
- 实现：`app/src/smart-clip/autoSplit.ts:371`、`:49`。

### AI 分析与八级分流
- 复制入库时本地预判打标（微秒级纯函数，零 AI 成本、静默不弹岛），`Ctrl+B` 才按标签分流。
- 分流顺序：超长 → 机器结构（JSON/链接/日志行/路径）→ 高熵（密钥/编码，覆盖率 >60%）→ 技术工件（代码/SQL/命令/配置/diff，≥2 类互异信号或代码 token 占比 ≥20%，命中不分词）→ 噪声（数字符号 >80%）→ 简单词串（<60 字、空白 ≥2 词、无句读）→ 过短（<20 字）→ 其余散文。分隔符/多行命中不直接判结构化，继续参与后续判定（顿号、分号、分段说明文常是自然语言）。
- 仅散文分支发起单次 AI 调用（关键词 + 要点 + 总结合并一次请求，输出 JSON，15s 超时）；每级分流结果都弹对应灵动岛提示。
- 开关：设置页「AI 智能提取」默认开启（KV `ai_analysis_enabled`，显式 `'0'` 关闭）；关闭后只做本地切分且不弹岛。
- 输入零注入：user 消息严格等于当前剪贴板内容（脱敏后），偏好摘要/习惯提示等外部内容不再进入请求。
- 长度上限默认 1000 字（KV `ai_analysis_max_chars`，钳制 100–10000，非法输入回落默认）。
- 实现：`app/src/smart-clip/analyzer.ts:110`、`app/src/smart-clip/analysis.ts:122`。

### 缓存窗口与飞行中去重
- 分析结果冷却缓存 300s，缓存键 = 分析前缀 + 内容指纹 + 分区版本号；缓存值带来源归属信封（指纹/长度/首尾采样），读取不匹配即按未命中（旧键条目自然失效，无需迁移）。
- 预判阶段即查缓存：命中直接弹成功岛，从不弹「AI 解析中」。
- 等待期连按 `Ctrl+B` 共享同一飞行中请求不重复耗 token；失败结果（超时/非 2xx/JSON 解析失败/产出为空）一律不缓存，修复后重按即真实重试。
- 实现：`app/src/smart-clip/analysis.ts`。

### 习惯画像
- 仅本地采集存储（KV `ai_habit_profile`）：粘贴长度/类型/语言分布、AI 采纳反馈（展示的关键词被粘贴数量）、topExtractors。
- 画像**不参与 AI 请求**（输入零注入）：原「偏好摘要拼进 user prompt」与「AI 提取器习惯提示」均已移除。
- 画像版本号仍写入分析缓存键，仅作分区因子；环盘粘贴与钉住行为经 `ring:habit` 跨窗口回主窗口落库。
- 实现：`app/src/smart-clip/habitProfile.ts`。

### 环形气泡窗（Ctrl+B 两阶段上屏）
- 按下瞬间按预判结果弹岛：AI 链路 →「AI 解析中」驻留岛（sticky）；本地分支/缓存命中 → 结果岛直出。
- overlay 窗口创建与解析并行推进；本地片段就绪即显示基础环，AI 产出完成后去重并入补建气泡，环心控制盘计数刷新。
- 片段经空白归一化判重（Windows 剪贴板常带不可见空白差异）；**唯一内容源 = 按下瞬间的系统剪贴板**，解析失败只降级为本次原文单段，不回退历史条目。
- 剪贴板为空/文件列表/图片无二维码：灵动岛提示后不开环。
- 每环 8 槽、最多 24 段（3 页）；环心控制盘（RingHub）展示原文预览、AI 状态条、导航行与页码点。
- 实现：`app/src/commands/local/BubbleToggleCommand.ts:153`、`app/src/smart-clip/ringSegments.ts:15`。

### 环内交互与钉住
- 方向键在当前页槽位间空间导航（不跨页），`PgUp`/`PgDn` 翻页并选中该页首项，`Enter` 粘贴选中片段后销毁环，`Esc`/失焦关闭；键盘全部收口在 RingOverlay 组件自治。
- 钉住把片段创建为独立常驻小气泡窗（`focus: false` 不抢目标应用焦点），点击卡片复制到剪贴板（带已复制反馈，不模拟粘贴、不自动隐藏），钉住行为计入习惯画像。
- 选中的二维码图片条目把解码链接当文本参与切分，`Enter` 直接粘贴链接。
- 实现：`app/components/ring/RingOverlay.vue:127`、`app/pages/bubble.vue:390`。

## 边界与限制

- 处理开关 KV `smart_clip_mode`：仅 `off`/`on` 两态（旧值 `auto`/`scheme`/`ai` 读取时归一为 `on`）；关闭不影响 `Ctrl+B` 按需 AI 分析。
- 解析对象仅文本：文件条目一律不支持；图片仅在 10 秒内入库且识别出二维码时取其文本。
- 环片段上限 24 段/3 页；内存 store 上限 30 条（气泡窗口只消费最近条目）。
- AI 分析默认不外发：代码/JSON/SQL/命令/配置/diff 与密钥/编码内容一律本地处理；散文夹密钥发送前脱敏为 `[REDACTED]`（脱敏占位符不得作为关键词透出）。
- 恰好等于长度上限视为未超长；恰好 20 字可送 AI；空内容/纯空白 sanitize 后为空归入过短拦截。
- 输出语言跟随内容主语言（与 UI 语言无关）；keywords / bullets 各截前 5，三字段全空视为失败不缓存。
- 提供商三种：`openai-compat`（默认）/ `anthropic` / `custom`（JSON 模板存 KV `ai_custom_config`，结构校验与执行在 Rust 侧）；API key 独立存储并迁移。
- 习惯数据永不离开本地 db，也不再以任何形式进入 AI 请求。
- 未配置提供商（缺 baseUrl/apiKey，custom 缺模板）→ 弹岛「请先配置 AI 提供商」，不发起任何请求；AI 错误经 `classifyAiError` 归类为网络/超时/HTTP/模型/未知五类可读文案。
- 环会话以时间戳为纪元：环被关闭后旧异步流程自我失效，不跨会话持久化。
- 环 overlay 窗口 920×640，位于光标所在显示器正中（不跟随鼠标）；ready 握手超时 8s 放弃开环不留幽灵环。
- 环活跃期间豁免主窗口失焦自动隐藏，并收掉已显示的 tooltip。
