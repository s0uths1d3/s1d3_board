# 截图（snip）

> **已实现（2026-10）**·P0/P1 全部落地，仅 P2（长截图 / AI 识图）为远期占位。全局快捷键唤起的区域截图工具，参照 Snipaste / 微信截图等主流工具，与剪贴板模块深度融合：截图自动成为可搜索、可收藏、可再粘贴的剪贴板图片条目。实现规格见 [screenshot-spec.md](../screenshot-spec.md)。

## 功能总览

> 按 P0（核心闭环）/ P1（增强）/ P2（远期）分期；快捷键默认 `Ctrl+Alt+A`（可在设置页录制修改）。

### P0 核心闭环

| 功能 | 说明 | 入口 / 快捷键 |
|---|---|---|
| 全局唤起 | 任意应用中唤起截图，光标所在显示器冻结画面 + 半透明遮罩 | `Ctrl+Alt+A`（全局） |
| 拖拽框选 | 十字线辅助、实时尺寸提示（W×H 像素） | 鼠标拖拽 |
| 选区调整 | 8 向手柄缩放 + 选区内拖动移动；方向键微移 1px（Shift=10px） | 鼠标 / 方向键 |
| 窗口识别吸附 | 悬停自动高亮光标处窗口边界，单击选整窗 | 鼠标悬停 / 单击 |
| 放大镜取色 | 跟随光标的像素放大镜 + RGB/HEX 色值，点击复制色值（入文本历史 + 岛提示） | 自动跟随光标 |
| 确认复制 | 裁剪 → 写系统剪贴板（任意应用可粘贴）+ 自动入剪贴板历史 + 灵动岛「已截图」（含缩略图与二维码识别） | `Enter` / 工具条「复制」 |
| 保存文件 | PNG/JPEG（质量可调）保存到指定目录（默认每次询问） | 工具条「保存」 |
| 取消 | 关闭覆盖窗不留痕 | `Esc` / 右键 / 工具条「取消」 |
| 多显示器与 DPI | 光标在哪屏截哪屏；混合 DPI 下选区与产物像素级一致 | 自动 |
| 截图入历史 | `type='image'`、来源标记 `s1d3-board`：可搜索、收藏、转待办/便签、添加常用剪贴、序列粘贴——剪贴板模块全部能力自动生效 | 自动 |

## 关键行为

### 触发链路与「先截后窗」
- 快捷键 → **先**调 Rust `snip_capture_screen` 整屏截屏落盘（imgfile: 引用）→ **后**创建透明覆盖窗展示冻结画面。顺序保证自绘遮罩不会入镜；不隐藏主窗口（允许截面板自身）。
- 覆盖窗为透明置顶无边框窗铺满光标所在显示器（逻辑尺寸=物理/scale），不进系统 fullscreen。

### 与剪贴板的融合
- 确认后：Rust 侧裁剪落盘（sha256 内容寻址，与既有图片条目同一存储与 LRU 缓存）→ 写系统剪贴板（CF_DIB，写入前先抑制「已复制」误报岛与使用计数双计）→ 以 `type='image'` + `source_app='s1d3-board'` 入库 → 弹「已截图」岛（kind `screenshot`，384px 缩略图 + quircs 二维码识别结果）。
- 剪贴板模块的搜索 / 高亮 / 收藏 / 转待办 / 转便签 / 常用剪贴 / 序列粘贴 / 图片查看器对截图条目全部自动生效，零额外开发。
- 快捷键粘贴（Ctrl+Shift+N）与常用剪贴直达（Ctrl+N）同样覆盖截图条目。

### 隐私与统计
- 隐私模式（暂停记录）下截图可用但不落库、不弹岛、不计数。
- P0 埋点复用 `clip_image`；P1 切换为独立字段 `clip_screenshot`（含 daily_stat 迁移 v23 与统计页指标卡）。

## 边界与限制

- **平台**：P0 仅 Windows（GDI BitBlt，零新增依赖）；macOS / Linux X11 列 P1（需权限检测/引导）；Wayland 永久不支持（设置置灰 + 提示，与应用时长模块同降级模式）。
- **单屏语义**：光标所在屏；跨屏拖选不支持（多屏各自触发）。
- **贴图为会话级**：重启后消失，不持久化（与便签钉选一致）。
- **截图上限**：沿用图片存储 20MB 单条上限与缓存目录清理策略（收藏豁免）。
