# 截图（snip）

> **已实现（2026-11）**·P0 / P1 / P2 全部落地（P2 长截图与 AI 识图仅 Windows 验证）。全局快捷键唤起的区域截图工具，参照 Snipaste / 微信截图等主流工具，与剪贴板模块深度融合：截图自动成为可搜索、可收藏、可再粘贴的剪贴板图片条目。实现规格见 [screenshot-spec.md](../screenshot-spec.md)。

## 功能总览

> 按 P0（核心闭环）/ P1（增强）/ P2（远期）分期；快捷键默认 `Ctrl+Alt+A`（可在设置页录制修改）。

| 功能 | 说明 | 入口 / 快捷键 |

## 关键行为

### 触发链路与「先截后窗」
- 快捷键 → **先**调 Rust `snip_capture_screen` 整屏截屏落盘（imgfile: 引用）→ **后**创建透明覆盖窗展示冻结画面。顺序保证自绘遮罩不会入镜；不隐藏主窗口（允许截面板自身）。
- 覆盖窗为透明置顶无边框窗铺满光标所在显示器（逻辑尺寸=物理/scale），不进系统 fullscreen。

### 与剪贴板的融合
- 确认后：Rust 侧裁剪落盘（sha256 内容寻址，与既有图片条目同一存储与 LRU 缓存）→ 写系统剪贴板（CF_DIB，写入前先抑制「已复制」误报岛与使用计数双计）→ 以 `type='image'` + `source_app='s1d3-board'` 入库 → 弹「已截图」岛（kind `screenshot`，384px 缩略图 + quircs 二维码识别结果）。
- 剪贴板模块的搜索 / 高亮 / 收藏 / 转待办 / 转便签 / 常用剪贴 / 序列粘贴 / 图片查看器对截图条目全部自动生效，零额外开发。
- 快捷键粘贴（Ctrl+Shift+N）与常用剪贴直达（Ctrl+N）同样覆盖截图条目。

### 长截图（P2）
- 选区确定后进入长截图模式：覆盖窗隐藏全部 UI（只留底部进度 HUD）并 `setIgnoreCursorEvents(true)` 让滚轮穿透到目标窗口，定时抓取选区画面。
- 帧去重：抓帧结果按内容寻址落盘（同一画面同一 `imgfile:` 引用），引用未变化即视为「未滚动」；静止约 2 秒且已抓到 ≥2 帧自动结束，20 秒硬上限，`Esc` 中止。
- 拼接：`snip_stitch_vertical` 逐对检测竖向重叠（行灰度签名，排除右侧滚动条区域），无重叠的帧跳过，宽度不一致直接报错。
- 结果由主窗口统一处理（覆盖窗无数据库连接）：写剪贴板 + 入历史 + 岛「长截图完成」，隐私模式只写剪贴板。

### 快速访问条
- 截图确认（写剪贴板 + 入历史 + 岛）后，在选区下方 8px 处浮现小工具条；下方放不下则翻到选区上方，水平/垂直均钳制在显示器内（含负原点副屏）。
- 按钮：贴图 / 上传并复制链接（未配置地址时隐藏）/ 打开剪贴板历史；文字识别只在截图编辑器工具条（需要预览确认）。
- 动作统一交主窗口执行（抑制标记、岛、数据库都在主窗口上下文），子窗口只发动作名；触发后立即收起。
- 4 秒无交互自动收起（悬停暂停计时，移出后 2.5 秒），`Esc` 立即收起；显示不抢焦点，不打断用户粘贴。
- 窗口预热常驻（固定 label `snip-quickbar`），显示只做改尺寸/改位置/投数据，避免 1~3 秒建窗延迟。

### 反馈与层级
- 截图会话期间灵动岛**不弹窗**（岛是常驻置顶窗，层级高于截图覆盖窗，会挡住选区/工具条）；会话开始时先收起停留中的岛。
- 所有截图内操作（OCR / 自动打码 / 长截图 / AI 识图 / 上传 / 保存）的反馈改为**覆盖窗内提示条**：成功 3 秒、失败 8 秒（红色，含失败原因原文）。
- 同一份通知仍由主窗口静默写入灵动岛历史（含失败原因），事后可在「灵动岛历史」回查；出站 SSE/Webhook 订阅者不受影响。

### 隐私与统计
- 隐私模式（暂停记录）下截图可用但不落库、不弹岛、不计数（长截图同样适用）。
- P0 埋点复用 `clip_image`；P1 切换为独立字段 `clip_screenshot`（含 daily_stat 迁移 v23 与统计页指标卡）。

## 边界与限制

- **平台**：P0 仅 Windows（GDI BitBlt，零新增依赖）；macOS / Linux X11 列 P1（需权限检测/引导）；Wayland 永久不支持（设置置灰 + 提示，与应用时长模块同降级模式）。
- **OCR**：Windows 原生 `Windows.Media.Ocr`，需系统安装对应识别语言包；无可用语言时工具条隐藏 OCR / 自动打码入口。
- **长截图**：仅 Windows 验证；依赖页面可滚动且滚动条不在选区右侧 24px 内；固定表头/视差内容会重复出现在拼接结果中。
- **单屏语义**：默认截取全屏并集（支持跨屏框选）；设置可回退「仅光标所在屏」。混合 DPI 多屏下非光标屏内容存在缩放开销。
- **贴图为会话级**：重启后消失，不持久化（与便签钉选一致）。
- **截图上限**：沿用图片存储 20MB 单条上限与缓存目录清理策略（收藏豁免）。
