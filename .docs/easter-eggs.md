# S1d3 Board 彩蛋说明

> 本文档与实现严格同步，以代码为准（节日彩蛋实现：`app/festival-eggs/` 独立模块；s1d3 彩蛋与岛显示层：`app/pages/bubble.vue`；测试日期注入：`scripts/tauri.mjs`）

应用当前包含两类彩蛋：**s1d3 隐藏动画**（内容触发，保持现状不受开关控制）与**节日限时主题**（日期触发，收口在 `festival-eggs` 独立模块、经通用挂载点注入业务界面）。节日彩蛋受设置页总开关控制（设置 → 通用 → 外观 → 节日彩蛋，默认开）。

## 0. 模块化架构（festival-eggs 注入模型）

节日彩蛋是**独立目录**（`app/festival-eggs/`），业务组件只经 `~/festival-eggs` 公共出口拿"通用挂载点消费接口"，**不含任何具体节日知识**；新增/修改节日全部在模块目录内完成（见 §3.3 六步指南），业务文件零改动。

| 文件 | 职责 |
|---|---|
| `core.ts` | 节日判定纯函数（公历表 + 农历映射表）+ 测试日期钩子 `festivalNow()`；头注释含新增节日六步指南 |
| `state.ts` | 响应式节日单例：裸节日 ref + 对齐零点自续 ticker（跨零点自动切换）；`useFestivalEgg()` 返回叠加总开关后的最终节日（挂载点唯一消费口径） |
| `switch.ts` | 总开关（settings KV `festival_egg_enabled`，默认开）；`reloadFestivalEggSwitch()` 供岛窗口弹岛前重读（跨窗口同步） |
| `points.ts` | 主窗口点缀注册表：`POINT_CLASSES`（点缀位 → 节日 → 类名）/ `QUOTE_BANNERS`（节日 → 引言键） |
| `points/FestivalQuoteBanner.vue` | 统计页引言横幅挂载点组件 |
| `island/useIslandFestivalEgg.ts` | 岛窗口消费接口：`{ festival, tip, beforeShow }`；`ISLAND_QUIRKS` 弹岛行为注册表（中秋凌晨台词） |
| `island/FestivalIslandDecor.vue` | 岛装饰挂载点组件：`kind="border" / "badges" / "panel"` 三槽位，全部节日 SVG 分支收口于此 |
| `lang/*.toml` | 模块自有文案（顶层 `[festival]` 表，经 `i18n/messages.ts` 的 `withModuleMessages` 启动时合并进消息树） |
| `styles/festival.css` | 节日皮肤变量组 + 岛装饰全套样式（经 `nuxt.config.ts` css 数组全局注入，排在 main.css 后保持级联） |

激活模型：岛窗口是独立 webview（不引导 AppModule），故不走路由/模块系统，采用"首个消费者触发幂等 install"的自激活 composable——主窗口与岛窗口共用同一套 API。

## 1. 彩蛋总览

| 彩蛋 | 触发方式 | 呈现位置 | 频次 | 受总开关控制 |
|---|---|---|---|---|
| s1d3 隐藏动画 | 复制 / 剪切 / 粘贴的内容恰好为 `s1d3` 四个字 | 灵动岛胶囊 | 每次命中播放 | 否（内容彩蛋，不属于节日体系） |
| 节日限时主题 | 日历命中节日当天（见 §3 判定表） | 灵动岛整体换装 + 主窗口局部点缀 | 节日全天自动生效 | 是 |

## 2. s1d3 隐藏动画

### 2.1 触发条件

判定收口在岛显示层（`applyIsland`），需**同时满足**：

| 条件 | 说明 |
|---|---|
| 操作类型 | 文本**复制**（copy）/ **剪切**（cut）/ **粘贴**（paste）——全局 Ctrl+C/X/V 钩子与原生事件均覆盖 |
| 内容匹配 | 文本 `trim()` 后**全等于** `s1d3`（忽略大小写，如 `S1D3`、` s1d3 ` 也命中） |
| 排除项 | 图片事件（缩略图/二维码链接文本）不触发；info/success/error 等系统提示不触发 |

> 注意是全等匹配而非 `includes`：开发中复制的项目路径（`E:\dev\s1d3\...`）、代码、URL 常含 s1d3 子串，宽匹配会把彩蛋变成高频误触发。

### 2.2 动画编排（约 1.9s，保底停留 2.6s）

| 时刻 | 演出 |
|---|---|
| 0.15s 起 | `s·1·d·3` 四枚金色键帽依次落位（spring 过冲，间隔 120ms） |
| 0.25s | 台词「你发现了隐藏彩蛋」淡入上浮 |
| 1.00s | 六颗金粒从键帽中心向星形六向迸发渐隐（错峰起爆） |
| 1.10s | 一道斜金光带从左掠到右（blur 柔化 + skew 速度感） |
| 1.25s | 四键错峰波浪跳（每键 +70ms 相位差） |
| 2.6s+ | 正常收回 |

风格约束：配色全部走主题 `--c-gold` token（随主窗口配色与节日主题同步）；缓动复用 spring 曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)`；彩蛋态隐藏常规图标/标签/原文/悬停动作，保留 ×N 重复徽标。

## 3. 节日限时主题

### 3.1 判定（`app/festival-eggs/core.ts`）

判定分两张表（`app/festival-eggs/core.ts`），跨零点由 `state.ts` 的自续 ticker 重算、岛窗口弹岛前即时重算，进出节日自然切换，无需轮询：

- **公历节日** `FESTIVAL_DAYS`：`[月, 日]` 数组命中
- **代码级禁用** `DISABLED_FESTIVALS`：命中的节日一律视为无节日（无 UI 开关，纯代码开关）；当前禁用 `programmer`——日期表/文案/皮肤/装饰全部保留，恢复 = 从集合移除即可
- **农历节日** `LUNAR_FESTIVAL_SOLAR`：专用公历映射表（收录年份每年一个 MMDD：七夕/中秋自 2020、春节/元宵/端午自 2026），不做完整农历换算——只为五个农历节日维护每年一个日期，数据量小且无换算错误风险；**未收录年份自然不触发**，每年初按万年历续表即可。**除夕不单列年份表**——恒为春节公历日期的前一天（无论当年腊月廿九还是三十），从春节映射派生，续表只维护春节一行、两节永不脱钩

装饰采用**骑缘底座徽章**：符号坐进与胶囊同底色/同描边的 22px 圆底座，圆心压在胶囊边框线上（半出半入），与边框"生长"为一体；符号实心填充继承节日强调色，镂空细节用胶囊底色。弹岛脉冲（`island-pill-new`）时徽章与胶囊**同帧联动**：双层金色涟漪（主环 0.6s + 余韵 0.75s 错峰，关键帧比例复刻胶囊环、scale 终值按小尺寸放大）+ spring 弹跳，形成整岛一体呼吸。徽章可悬停，弹全站统一 v-tip 气泡显示节日名（`festival.tip_*`，模块自有文案），且**气泡同步节日换装**——节日变量组定义在全局 `[data-festival]`（festival.css，与岛共用一份），vTip 指令把触发元素就近的 `data-festival` 复制到气泡上触发同一组变量（气泡底色/文字/金线边框全部随皮肤变色）。左右缘可越（窗口 440 > 胶囊 344），顶/底缘不出（窗口顶部无余量）。位置为**确定性散点**——手工选定的固定值，同一节日每次弹岛位置相同。胶囊内常规 kind 图标与文本预览不受影响。

### 3.2 换装机制

- 节日变量组（12 个 `--c-*` token：底色/描边/强调/文字三层次/阴影全套）定义在**全局** `festival-eggs/styles/festival.css` 的 `[data-festival='...']` 属性选择器下（经 `nuxt.config.ts` css 数组注入，排在 main.css 后保持级联），与 `data-scheme` 解耦——暖调/浅色/深色三种配色下观感统一；岛根节点（`.island-wrap`）与 v-tip 气泡（`.s1d3-tip`）共用这一份定义
- 胶囊、展开面板、金环脉冲、×N 徽标、s1d3 彩蛋键帽、面板行号/行数统计（`--c-ink-faint`）等 token 全部继承染色，零组件改动；面板内禁止写死色值（曾在节日深底下突兀）
- 每个节日配 `.island-pill` **双层光晕**（近层小 blur 高 alpha + 远层大 blur 低 alpha）：单层光晕边缘亮度突降会形成硬环；远层扩散半径受窗口余量约束
- 流光环（愚人节彩带 / 程序员节扫描光）用 `@property --fest-angle` 插值动画 conic-gradient 起始角——**不能 rotate div 本身**：矩形 div 旋转时四角会甩出圆环范围（表现为斜线扫出胶囊外）
- 窗口余量：宽 440 > 胶囊 344（两侧各 48px，供脉冲环扩散 ≈385px、光晕横向外扩与彩蛋扫光）；高 96 = 胶囊 40 + 底部 48px（光晕纵向外扩约 44px 完整渲染，余量不足时辉光在窗口底缘被物理裁切、表现为"直接消失"的硬边）；顶部由定位公式 y+12 与 wrap padding-top 8 提供约 20px

### 3.3 扩展新节日（全部在 festival-eggs 目录内，业务代码零改动）

1. **日期表**（`core.ts`）：公历节日进 `FESTIVAL_DAYS`（`[月, 日]` 条目）；农历节日进 `LUNAR_FESTIVAL_SOLAR` 映射表（当年公历 MMDD，未收录年份不触发）
2. **文案**（`lang/zh-cn.toml` / `lang/en-us.toml`）：`[festival]` 表加 `tip_<id>`（徽章 v-tip）等键
3. **皮肤**（`styles/festival.css`）：`[data-festival='<id>']` 追加 12 token 变量组（与既有皮肤同公式）+ 胶囊光晕（双层结构）与装饰样式
4. **岛装饰**（可选，`island/FestivalIslandDecor.vue`）：border / badges / panel 对应槽位加分支
5. **弹岛行为**（可选，`island/useIslandFestivalEgg.ts`）：`ISLAND_QUIRKS` 登记一行（纯函数改写载荷；跨弹岛记忆用模块级变量）
6. **主窗口点缀**（可选，`points.ts`）：`POINT_CLASSES` / `QUOTE_BANNERS` 登记一行

最后补 `festivalEggs.spec.ts` 判定用例。

### 3.4 总开关与跨窗口同步

- **设置入口**：设置 → 通用 → 外观 → 节日彩蛋（`UiToggleSwitch`，settings KV `festival_egg_enabled`，默认开）
- **门控口径**：`state.ts` 的 `useFestivalEgg()` 返回 `computed(() => (开关开 ? 裸节日 : null))`——关闭恒 null，所有挂载点（岛换装/徽章/面板装饰/主窗口点缀/弹岛行为）统一输出空
- **跨窗口**：岛窗口是独立 webview，模块级 ref 不随主窗口设置页更新——岛侧在 `beforeShow`（每次弹岛前）调用 `reloadFestivalEggSwitch()` 重读持久化值，同时消除首显 KV 未加载竞态
- **s1d3 内容彩蛋不受本开关影响**（不属于节日体系，保持现状零改动）

## 4. 测试方法

### 4.1 注入测试日期（无需等节日）

```bash
npm run tauri dev -- --time 260401   # 2026-04-01 愚人节 → 绿岛
npm run tauri dev --time=260401      # 等号形式同样生效
npm run tauri:dev -- --time 261224   # tauri:dev 快捷入口已包装
```

- 链路：`scripts/tauri.mjs` 剥离 `--time`（tauri CLI 不识别该参数）→ 注入环境变量 `VITE_TEST_DATE` → Vite 暴露给前端 → `festivalNow()` 解析 YYMMDD 为模拟"今天"（固定 12 点整避开零点边界）
- 未注入时 `festivalNow()` 返回真实当前时间，正常启动/生产行为不变
- 日期在 Nuxt dev server 启动时注入，dev 已在跑需重启命令才生效
- 启动日志会输出 `[tauri.mjs] 测试日期已注入: VITE_TEST_DATE=...`

### 4.2 触发 s1d3 彩蛋

复制、剪切或粘贴内容**恰好**为 `s1d3`（在便签新建一条内容为 s1d3 的便签后点「复制内容」即可）。剪切前剪贴板需为其他内容——先复制再剪切同段文本时剪贴板无变化，岛不弹。
